Frontend: React.js
Backend: Java + Spring Boot
Database: MySQL
Authentication: JWT later
Location: Browser Geolocation API
Communication: REST APIs

Starting :
npm create vite@latest frontend - used to create the starting structure for our React frontend.

A linter is a tool that checks your code for mistakes, potential problems, and bad coding practices while you're writing it. A linter can catch issues before they turn into bugs.

I have chose EsLint in this project -- ESLint checks your JavaScript/React code for common mistakes and warns you about problems.
For framework i have chose Javascript

inside package.json,  It lists the packages/dependencies that our React application needs.

npm install reads that file, downloads those packages, and puts them inside node_modules folder

main.jsx is the entry point of the React app. It loads the App component and renders it into the browser.

App.jsx is the main component where we’ll start building our Women Safety UI.

App.css and index.css are used for styling.

package.json stores project information, dependencies, and scripts like: npm run dev

vite.config.js contains Vite configuration.

index.html is the base HTML page where React gets mounted.

Dependencies: 
Spring Data JPA helps our Java application interact with the database without us manually writing SQL for every basic operation.
MySQL Driver allows the Java application to communicate with MySQL.
Validation helps us validate incoming data  --  for example, rejecting an empty phone number.
DevTools provides conveniences while developing, such as automatic application restart when appropriate.
